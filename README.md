# Malika Kamilzhanova — portfolio website

## Open locally
Open `index.html` in any browser. No internet or server needed.

## Structure
- `index.html` — page content
- `css/style.css` — design
- `css/fonts.css` — fonts (local)
- `js/main.js` — animations, menu, contact form
- `fonts/` — font files
- `images/` — SVG placeholders. Replace with real photos using the same file names
  (or change the `src` in `index.html`).

## Before publishing, replace these placeholders
- `https://github.com/YOUR_USERNAME` and `github.com/YOUR_USERNAME` (GitHub)
- `https://t.me/YOUR_CHANNEL` and `t.me/YOUR_CHANNEL` (Telegram channel)

## Publish on GitHub Pages
1. Create a new public repository on GitHub, e.g. `portfolio`.
2. Upload all files from this folder (keep the folder structure) and commit.
3. Go to Settings → Pages → Build and deployment → Source: "Deploy from a branch",
   Branch: `main`, folder: `/ (root)`, then Save.
4. After a minute the site is available at `https://YOUR_USERNAME.github.io/portfolio/`.
